# Finance

## Objectif

Valider la viabilité économique, la rentabilité et la bancabilité des projets de flexibilité industrielle.

La finance ne doit pas intervenir au début du processus.

La finance intervient après :

- la compréhension du besoin client
- l'identification du service
- la qualification de la flexibilité
- la définition du modèle économique
- la sélection du contrat
- l'allocation des risques

## Principe fondamental

Un projet rentable n'est pas nécessairement un bon investissement.

Un bon investissement doit être :

- rentable
- bancable
- exécutable
- robuste
- défendable en comité

## Pourquoi cette section existe

La plupart des business cases échouent pour l'une des raisons suivantes :

- revenus surestimés
- CAPEX sous-estimé
- dégradation ignorée
- disponibilité surestimée
- coûts opérationnels incomplets
- absence d'analyse de risque
- dépendance excessive aux revenus merchant
- absence de chemin vers la bancabilité

L'objectif est d'éviter ces erreurs.

## Questions Clés

Avant de recommander un projet, il faut répondre aux questions suivantes :

### Valeur

Quelle valeur est créée ?

Pour :

- le client
- ENGIE
- l'investisseur
- les partenaires

### Revenus

Les revenus sont-ils :

- mesurables
- défendables
- reproductibles
- diversifiés

Quelle part des revenus est :

- contractuelle
- merchant
- garantie
- variable

### Coûts

Tous les coûts sont-ils intégrés ?

- développement
- EPC
- batterie
- EMS
- raccordement
- maintenance
- optimisation
- assurance
- exploitation

### Risques

Quels sont les principaux risques ?

- marché
- client
- performance
- dégradation
- réglementation
- financement

### Rentabilité

Le projet crée-t-il suffisamment de valeur ?

Les principaux indicateurs sont :

- EBITDA
- Cash Flow
- NPV
- IRR
- Payback

### Bancabilité

Le projet est-il finançable ?

Facteurs favorables :

- revenus visibles
- contrepartie solide
- durée suffisante
- allocation claire des risques
- contrat robuste

## Sensibilités

Toute opportunité doit être testée selon plusieurs scénarios.

Variables recommandées :

- revenus merchant
- CAPEX
- OPEX
- disponibilité
- dégradation
- date de COD
- valeur résiduelle
- coût du capital

Le scénario downside est particulièrement important.

## Investment Committee

La finance alimente directement le comité d'investissement.

Les éléments attendus sont :

- NPV
- IRR
- Payback
- DSCR
- sensibilités
- downside case
- upside case
- recommandations

## Investment Killers

Les causes les plus fréquentes de rejet sont :

- revenus merchant surestimés
- bloc résiduel non démontré
- CAPEX non maîtrisé
- revenus insuffisamment contractualisés
- dégradation ignorée
- risques mal attribués
- financement non sécurisé

## Résultat Attendu

La section Finance doit permettre de répondre à une question simple :

Le projet crée-t-il suffisamment de valeur pour justifier l'investissement
