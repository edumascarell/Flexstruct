# Contracts

## Objectif

Sélectionner la structure contractuelle la plus adaptée à une opportunité de flexibilité.

Le contrat détermine :

- la création de valeur
- la répartition des revenus
- l'allocation des risques
- les responsabilités
- les droits de pilotage
- les conditions de financement

## Principes

Le contrat doit :

- protéger le besoin industriel du client
- permettre l'exécution opérationnelle
- répartir correctement les risques
- améliorer la bancabilité lorsque nécessaire

Le contrat est une conséquence du business model.

Il ne doit jamais être choisi avant la qualification de l'opportunité.

## Structures contractuelles principales

### Asset Sale

Le client possède l'actif.

### Storage as a Service

Le client achète un service.

### Flexibility as a Service

Le client achète un résultat.

### Shared Savings

La rémunération dépend des économies générées.

### Revenue Share

Les revenus sont partagés.

### Revenue Floor

Un revenu minimum est garanti.

### Tolling

La capacité est mise à disposition d'un tiers.

### vFPA

La valeur de la flexibilité est contractualisée à long terme.

### Merchant

Les revenus dépendent directement des marchés.

## Question centrale

Quel contrat permet de maximiser :

- la valeur client
- la rentabilité
- la bancabilité
- la capacité d'exécution

tout en protégeant les opérations industrielles ?

## Conclusion

Un bon contrat ne maximise pas uniquement les revenus.

Un bon contrat crée un équilibre durable entre :

- client
- fournisseur
- investisseur
- opérateur
- optimisateur
