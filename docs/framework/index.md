# Framework de Qualification des Opportunités de Flexibilité

## Pourquoi ce framework ?

La plupart des projets de flexibilité démarrent par la technologie.

BESS
→ Revenus
→ Business Case

Cette approche conduit souvent à des projets difficilement industrialisables.

- pour le client industriel
- pour ENGIE

---

## Les 5 principes de FLEXSTRUCT

### 1. Le client n'achète pas une batterie

Il achète :

- compétitivité
- continuité opérationnelle
- capacité d'électrification
- croissance

### 2. La technologie n'est qu'un moyen

BESS, DSM, PV, EV Charging, V2G et EMS sont des outils.

### 3. La flexibilité doit être qualifiée

Toute flexibilité n'est pas commercialisable.

### 4. Le risque doit être attribué

Chaque risque doit être porté par l'acteur le mieux placé pour le gérer.

### 5. La bancabilité est essentielle

Un projet rentable n'est pas forcément finançable.
