# Comité d'Investissement

## Objectif

Transformer une opportunité commerciale en une décision d'investissement structurée, documentée et défendable.

Le Comité d'Investissement doit déterminer si le projet mérite l'engagement de ressources financières, commerciales, techniques et opérationnelles.

La décision ne repose pas uniquement sur la rentabilité théorique.

Elle doit intégrer :

- la valeur créée pour le client
- l'intérêt stratégique
- la robustesse du modèle économique
- la qualité de la contrepartie
- la faisabilité technique
- la structure contractuelle
- l'allocation des risques
- la capacité de financement
- la capacité d'exécution
- la réplicabilité

## Principe fondamental

Un bon projet techniquement réalisable n'est pas nécessairement un bon investissement.

Un projet rentable dans le scénario de référence n'est pas nécessairement bancable.

Un projet bancable n'est pas nécessairement stratégique.

La décision doit trouver un équilibre entre :

- valeur client
- valeur pour le fournisseur
- risque
- rentabilité
- visibilité
- capacité d'exécution
- potentiel de réplication

## Question centrale

Le projet crée-t-il suffisamment de valeur pour justifier les risques et les ressources engagées ?

## Décision demandée

La demande présentée au Comité doit être explicite.

Elle peut concerner :

- financement du développement
- validation du business case
- engagement commercial
- signature d'un contrat
- investissement dans un actif
- acquisition d'un projet
- lancement de la construction
- sélection d'un partenaire
- autorisation de négociation finale
- passage à une nouvelle phase
- validation d'une exception
- abandon du projet

Le Comité ne doit pas avoir à deviner la décision attendue.

## Résumé exécutif

Le résumé exécutif doit permettre de comprendre le projet rapidement.

Il doit répondre aux questions suivantes :

- Quel est le problème industriel du client ?
- Quelle solution est proposée ?
- Pourquoi le projet est-il pertinent maintenant ?
- Quelle valeur est créée ?
- Quel est le modèle économique ?
- Quels sont les principaux risques ?
- Quelle décision est demandée ?
- Quelles conditions doivent être remplies ?

## Besoin industriel du client

Le point de départ est le Customer Job.

La présentation doit expliquer ce que le client cherche à accomplir.

Les objectifs peuvent inclure :

- respecter le plan de production
- lancer une nouvelle ligne
- électrifier un procédé
- augmenter la capacité
- réduire les pointes
- maîtriser le coût énergétique
- améliorer l'autoconsommation
- réduire le délai de raccordement
- renforcer la résilience
- atteindre un objectif de décarbonation

## Pain industriel

Le projet doit répondre à un pain réel, documenté et suffisamment important.

Les pains peuvent inclure :

- capacité électrique insuffisante
- délai de raccordement incompatible
- risque de retard industriel
- augmentation du coût par unité produite
- difficulté à intégrer de nouvelles charges
- limitation de la croissance
- risque de perte de production
- investissement réseau élevé
- volatilité budgétaire
- dépendance à une solution provisoire

Les revenus FCR, aFRR, mFRR ou d'arbitrage ne constituent pas le pain industriel.

Ils représentent des sources potentielles de monétisation.

- réduction du risque opérationnel

- Revenue Floor
- Tolling
- garanties
- allocation claire des risques
- technologie éprouvée
- DSCR suffisant

Un projet rentable n'est pas nécessairement bancable.

## Décision positive

Une décision positive peut être recommandée lorsque :

- le besoin client est confirmé
- la proposition de valeur est claire
- la solution est faisable
- le client est engagé
- la structure contractuelle est robuste
- le scénario downside reste acceptable
- les risques sont attribués
- le financement est crédible
- l'organisation peut exécuter
- le projet répond aux critères d'investissement

## Décision positive sous conditions

Une approbation conditionnelle peut être recommandée lorsque le projet est attractif mais dépend encore de certains éléments.

Les conditions peuvent inclure :

- amélioration du contrat
- hausse du floor
- réduction du CAPEX
- garantie supplémentaire
- validation du raccordement
- sécurisation du financement
- clarification des responsabilités
- obtention d'un permis
- amélioration du scénario downside
- engagement du client

## Décision de révision

Le Comité peut demander une révision lorsque :

- le service est mal défini
- le dimensionnement n'est pas optimisé
- le contrat ne protège pas suffisamment les parties
- certains risques ne sont pas attribués
- les hypothèses sont insuffisamment documentées
- le financement n'est pas défini
- la gouvernance est trop complexe
- des données complémentaires sont nécessaires

## Décision négative

Une décision négative peut être recommandée lorsque :

- le besoin client n'est pas réel
- le client n'est pas prêt à payer
- la flexibilité n'est pas disponible
- le projet compromet les opérations industrielles
- la rentabilité dépend d'hypothèses excessives
- le scénario downside est inacceptable
- le contrat n'est pas exécutable
- les risques sont disproportionnés
- le financement n'est pas crédible
- le projet ne correspond pas à la stratégie
