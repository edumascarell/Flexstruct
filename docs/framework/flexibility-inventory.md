# Flexibility Inventory
 
## Objectif
 
Identifier les sources de flexibilité disponibles sur un site industriel.
 
## BESS
 
Utilisation :
 
- stockage d'énergie
- peak shaving
- arbitrage
- services système
 
Points d'attention :
 
- disponibilité
- cycles
- dégradation
 
## Photovoltaïque
 
Utilisation :
 
- autoconsommation
- réduction des coûts
 
Points d'attention :
 
- intermittence
- profil de production
 
## Demand Side Management
 
Utilisation :
 
- effacement
- modulation de charge
 
Points d'attention :
 
- impact opérationnel
- acceptation industrielle
 
## EV Charging
 
Utilisation :
 
- smart charging
- pilotage de charge
 
Points d'attention :
 
- disponibilité des véhicules
- contraintes opérationnelles
 
## V2G
 
Utilisation :
 
- flexibilité distribuée
- services système
 
Points d'attention :
 
- réglementation
- disponibilité des véhicules
 
## Génération de Secours
 
Utilisation :
 
- secours
- réduction des pointes
 
Points d'attention :
 
- contraintes environnementales
- disponibilité du carburant
 
## Process Flexibility
 
Utilisation :
 
- décalage de consommation
- optimisation énergétique
 
Points d'attention :
 
- impact sur la production
- contraintes qualité
 
## Principe
 
Toute flexibilité n'est pas commercialisable.
 
Chaque source doit être qualifiée avant d'être intégrée dans une offre.
