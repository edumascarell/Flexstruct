# Catalogue de Services

## Principe

Le client n'achète pas une technologie.

Le client achète un service.

La technologie est un moyen.

## Continuité Opérationnelle

Objectif :

Maintenir la production malgré les incidents.

Technologies possibles :

- BESS
- génération de secours
- EMS

Valeur créée :

- réduction du risque d'arrêt
- protection de la production
- sécurisation des opérations

## Capacité d'Électrification

Objectif :

Permettre le raccordement de nouvelles charges.

Technologies possibles :

- BESS
- EMS
- pilotage de charge

Valeur créée :

- réduction du délai projet
- augmentation de la capacité disponible
- accélération de l'électrification

## Peak Shaving

Technologies possibles :

- BESS
- EMS
- DSM

Valeur créée :

- optimisation du raccordement

Technologies possibles :

- meilleure visibilité budgétaire

## Service First

Le besoin du client détermine :

- le service
- la technologie
- le modèle économique
- le contrat

Jamais l'inverse.
