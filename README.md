# FLEXSTRUCT

## Plateforme d'Intelligence pour la Flexibilité Industrielle

Framework de qualification, structuration et monétisation des opportunités de flexibilité énergétique en Europe.

---

## Thèse centrale

Le client industriel n'achète pas une batterie.

Il achète :

- la compétitivité
- la capacité d'électrification
- la continuité opérationnelle
- la croissance

Les batteries, le DSM, le photovoltaïque, le smart charging et le V2G ne sont que des outils.

Le véritable produit est un service.
